本目录描述 ResumeMatch 的 PDF/DOCX 简历导入能力，供前端、后端、测试和文档维护人员共同使用。

## 当前版本

- 文档版本：`1.0.0`
- API 前缀：`/api`
- 支持来源：文本型 PDF、DOCX
- 文件大小：不超过 10 MB
- 不支持：扫描版 PDF、图片、OCR、整段简历文本粘贴导入

## 核心约定

1. 文件导入只生成待确认候选结果，不直接创建正式版本。
2. 用户确认前状态为 `needs_review`，确认后写入 `Draft`。
3. 必须识别字段缺失不导致整体导入失败，应通过 `issues` 提醒用户补充。
4. 无法归类的内容必须保存在 `unmappedFragments`，不得静默丢弃。
5. 上传原文件仅用于临时解析；解析完成后删除，只长期保存原始文本快照和结构化结果。
6. `ResumeDocument` 是解析、编辑、分析和导出的公共数据契约。
