## 当前版本

- 文档版本：`1.0.0`
- API 前缀：`/api`
- 输入：不可变的 `ResumeVersion ID`、模板 ID、导出格式
- 输出格式：可编辑 DOCX、PDF
- 模板数量：首版提供两份人工维护的 Word 模板
- PDF 转换：LibreOffice Headless

## 核心约定

1. 导出只读取不可变的 `ResumeVersion` 快照，不直接读取 Draft。
2. 普通版本和 JD 优化版本共用同一个导出服务。
3. 相同版本、模板和格式应生成内容一致的文件。
4. 导出采用异步任务，创建后通过 `exportId` 查询状态。
5. 只有 `status=completed` 时允许下载。
6. DOCX 是模板渲染的基础产物；PDF 由同一 DOCX 经 LibreOffice 转换，二者内容必须一致。
7. 客户端不能提交或拼接本地文件路径，下载必须通过受控接口完成。
8. 导出失败不得修改 ResumeVersion、Draft 或其它业务数据。
