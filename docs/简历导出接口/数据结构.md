# 数据结构

## 1. 通用响应

JSON 成功响应统一为：

```json
{
  "data": {},
  "requestId": "req_export_example"
}
```

JSON 错误响应统一为：

```json
{
  "error": {
    "code": "EXPORT_NOT_FOUND",
    "message": "导出任务不存在。",
    "details": {
      "exportId": "export_unknown"
    }
  },
  "requestId": "req_export_example"
}
```

下载成功响应为二进制文件流，不使用 JSON 包装。

## 2. ExportTemplate

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 否 | 稳定模板 ID |
| `name` | string | 否 | 中文展示名称 |
| `description` | string | 否 | 模板用途说明 |
| `version` | string | 否 | 模板内容版本 |
| `layout` | enum | 否 | `single_column` 或 `two_column` |
| `supportedFormats` | ExportFormat[] | 否 | 支持的导出格式 |
| `previewUrl` | string | 否 | 受控预览图地址 |
| `isDefault` | boolean | 否 | 是否为默认模板 |

首版模板 ID 固定为 `classic_single_column` 和 `modern_two_column`。

## 3. CreateExportRequest

| 字段 | 类型 | 必填 | 约束 |
| --- | --- | --- | --- |
| `templateId` | string | 是 | 必须来自模板列表且当前可用 |
| `format` | ExportFormat | 是 | `docx` 或 `pdf` |

`versionId` 位于 URL path，不在请求体中重复提交。

## 4. ExportRecord

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 否 | 导出任务 ID |
| `resumeVersionId` | string | 否 | 输入的不可变版本 ID |
| `templateId` | string | 否 | 使用的模板 ID |
| `templateVersion` | string | 否 | 创建任务时锁定的模板版本 |
| `format` | ExportFormat | 否 | 输出格式 |
| `status` | ExportStatus | 否 | 当前任务状态 |
| `fileName` | string | 是 | 完成后生成的安全文件名 |
| `mimeType` | string | 是 | 完成后的文件 MIME |
| `fileSizeBytes` | integer | 是 | 完成后的文件大小，必须大于 0 |
| `downloadUrl` | string | 是 | 完成后的受控下载地址 |
| `error` | ExportError | 是 | 失败信息；仅 `failed` 时非空 |
| `createdAt` | string(date-time) | 否 | 任务创建时间 |
| `updatedAt` | string(date-time) | 否 | 最近更新时间 |
| `completedAt` | string(date-time) | 是 | 成功完成时间 |

这里的“可空”表示字段始终返回，但值可以为 `null`。内部 `filePath` 不属于公开 API 模型。

## 5. ExportError

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | string | 稳定错误码 |
| `message` | string | 可展示的中文提示 |

任务失败信息不包含 `details`，避免持久化内部路径和第三方原始输出；同步接口错误仍使用通用错误结构。

## 6. 枚举

### ExportFormat

| 值 | 说明 |
| --- | --- |
| `docx` | 可编辑 Word 文档 |
| `pdf` | 由 DOCX 转换得到的 PDF |

### ExportStatus

| 值 | 说明 |
| --- | --- |
| `queued` | 已入队，等待 Worker |
| `processing` | 正在渲染或转换 |
| `completed` | 文件可下载 |
| `failed` | 任务失败，终态 |

### 字段组合约束

| 状态 | 文件字段 | `error` | `completedAt` |
| --- | --- | --- | --- |
| `queued` | 全部为 `null` | `null` | `null` |
| `processing` | 全部为 `null` | `null` | `null` |
| `completed` | 全部非空 | `null` | 非空 |
| `failed` | 全部为 `null` | 非空 | `null` |

## 7. 错误码

| HTTP | 错误码 | 场景 |
| --- | --- | --- |
| 404 | `VERSION_NOT_FOUND` | 指定简历版本不存在 |
| 404 | `EXPORT_TEMPLATE_NOT_FOUND` | 模板不存在或不可用 |
| 404 | `EXPORT_NOT_FOUND` | 导出任务不存在 |
| 409 | `EXPORT_NOT_READY` | 任务尚未完成，不能下载 |
| 409 | `EXPORT_TASK_FAILED` | 任务已失败，不能下载 |
| 422 | `EXPORT_FORMAT_NOT_SUPPORTED` | 格式不在模板支持范围内 |
| 500 | `EXPORT_FAILED` | 模板渲染、文件保存或转换失败 |
| 503 | `EXPORT_DEPENDENCY_MISSING` | PDF 转换依赖不可用 |
