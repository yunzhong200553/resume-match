# 接口参考

## 1. 获取导出模板

获取当前可用模板及其支持格式，用于导出页面初始化。

### 请求

```http
GET /api/export-templates HTTP/1.1
Accept: application/json
```

无请求参数。

### 成功响应

HTTP 状态：`200 OK`。完整响应见 [模板列表响应.json](示例/模板列表响应.json)。

### 业务规则

- 只返回当前可用模板，按服务端配置顺序排列。
- `id` 是创建导出任务时使用的稳定标识，客户端不得使用模板名称代替。
- 模板预览地址只用于展示，不代表最终下载地址。

## 2. 创建导出任务

对指定不可变简历版本创建 DOCX 或 PDF 导出任务。

### 请求

```http
POST /api/resume-versions/{versionId}/exports HTTP/1.1
Content-Type: application/json
```

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `versionId` | path | string | 是 | 不可变 ResumeVersion ID |
| `templateId` | body | string | 是 | 可用模板 ID |
| `format` | body | enum | 是 | `docx` 或 `pdf` |

完整请求见 [创建导出任务请求.json](示例/创建导出任务请求.json)；将 `format` 改为 `docx` 即可创建 DOCX 任务。

### 成功响应

HTTP 状态：`202 Accepted`。完整响应见 [创建导出任务响应.json](示例/创建导出任务响应.json)。

响应头：

```http
Location: /api/exports/export_20260318_001
Retry-After: 1
```

### 业务规则

1. 创建时锁定 `ResumeVersion` 和 `templateVersion`，后续模板更新不影响该任务。
2. 每次调用创建一条新记录，因此接口不具备幂等性。
3. DOCX 和 PDF 使用同一套模板渲染结果；PDF 在 DOCX 生成后转换。
4. 成功创建只表示任务已入队，不表示文件已生成。
5. 创建失败或后台任务失败均不得修改简历版本。

### 错误响应

| HTTP | 错误码 | 场景 |
| --- | --- | --- |
| 404 | `VERSION_NOT_FOUND` | versionId 不存在 |
| 404 | `EXPORT_TEMPLATE_NOT_FOUND` | templateId 不存在或不可用 |
| 422 | `VALIDATION_ERROR` | 请求体缺失或字段类型错误 |
| 422 | `EXPORT_FORMAT_NOT_SUPPORTED` | 模板不支持指定格式 |
| 503 | `EXPORT_DEPENDENCY_MISSING` | 请求 PDF 且 LibreOffice 不可用 |

示例见 [版本不存在错误响应.json](示例/版本不存在错误响应.json)、[模板不存在错误响应.json](示例/模板不存在错误响应.json) 和 [导出依赖缺失错误响应.json](示例/导出依赖缺失错误响应.json)。

## 3. 获取导出状态

查询异步任务的最新状态和下载信息。

### 请求

```http
GET /api/exports/{exportId} HTTP/1.1
Accept: application/json
```

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `exportId` | path | string | 是 | 导出任务 ID |

### 成功响应

HTTP 状态：`200 OK`。无论任务处于哪个状态，只要记录存在都返回 200：

- `queued`：见 [创建导出任务响应.json](示例/创建导出任务响应.json)。
- `processing`：见 [导出处理中响应.json](示例/导出处理中响应.json)。
- `completed`：见 [导出完成响应.json](示例/导出完成响应.json)。
- `failed`：见 [导出失败响应.json](示例/导出失败响应.json)。

### 错误响应

| HTTP | 错误码 | 场景 |
| --- | --- | --- |
| 404 | `EXPORT_NOT_FOUND` | exportId 不存在 |

## 4. 下载导出文件

下载已完成任务生成的 DOCX 或 PDF 文件。

### 请求

```http
GET /api/exports/{exportId}/download HTTP/1.1
Accept: application/pdf, application/vnd.openxmlformats-officedocument.wordprocessingml.document
```

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `exportId` | path | string | 是 | 状态为 `completed` 的导出任务 ID |

### 成功响应

HTTP 状态：`200 OK`，响应体为二进制文件流，不使用通用 JSON 包装。PDF 示例响应头：

```http
Content-Type: application/pdf
Content-Disposition: attachment; filename="resume-classic-single-column.pdf"; filename*=UTF-8''%E7%AE%80%E5%8E%86-%E7%BB%8F%E5%85%B8%E5%8D%95%E6%A0%8F.pdf
Content-Length: 184320
Cache-Control: private, no-store
```

DOCX 使用 MIME `application/vnd.openxmlformats-officedocument.wordprocessingml.document` 和 `.docx` 扩展名。

### 业务规则

- 只有 `completed` 状态允许下载。
- 下载不改变任务状态，也不创建新导出记录。
- 响应文件必须与任务记录中的 `format`、`mimeType` 和 `fileName` 一致。
- 客户端应使用 `Content-Disposition` 提供的文件名，不自行拼接服务端路径。

### 错误响应

| HTTP | 错误码 | 场景 |
| --- | --- | --- |
| 404 | `EXPORT_NOT_FOUND` | exportId 不存在 |
| 409 | `EXPORT_NOT_READY` | 状态为 `queued` 或 `processing` |
| 409 | `EXPORT_TASK_FAILED` | 状态为 `failed` |
| 500 | `EXPORT_FAILED` | 文件记录存在但读取或传输失败 |

完整错误示例见 [导出未就绪错误响应.json](示例/导出未就绪错误响应.json)。客户端只依赖 `error.code` 处理分支，不依赖中文 `message`。
