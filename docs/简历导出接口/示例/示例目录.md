# JSON 示例目录

所有文件均为标准 JSON，可直接用于前后端联调、Mock 和契约测试。

## 模板与创建任务

| 文件 | 场景 |
| --- | --- |
| [模板列表响应.json](模板列表响应.json) | 获取两份可用模板 |
| [创建导出任务请求.json](创建导出任务请求.json) | 创建 PDF 导出任务 |
| [创建DOCX导出任务请求.json](创建DOCX导出任务请求.json) | 创建 DOCX 导出任务 |
| [创建导出任务响应.json](创建导出任务响应.json) | 任务进入 `queued` 状态 |

## 状态查询

| 文件 | 场景 |
| --- | --- |
| [导出处理中响应.json](导出处理中响应.json) | Worker 正在生成文件 |
| [导出完成响应.json](导出完成响应.json) | PDF 文件生成完成，可下载 |
| [DOCX导出完成响应.json](DOCX导出完成响应.json) | DOCX 文件生成完成，可下载 |
| [导出失败响应.json](导出失败响应.json) | 后台任务失败 |

## 错误响应

| 文件 | 场景 |
| --- | --- |
| [版本不存在错误响应.json](版本不存在错误响应.json) | ResumeVersion 不存在 |
| [模板不存在错误响应.json](模板不存在错误响应.json) | 模板不存在或不可用 |
| [导出依赖缺失错误响应.json](导出依赖缺失错误响应.json) | LibreOffice 不可用 |
| [导出未就绪错误响应.json](导出未就绪错误响应.json) | 文件尚未生成时请求下载 |
