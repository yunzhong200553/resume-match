## 文档规范

所有 API 文档统一遵循 [接口文档编写指南](简历导入接口/接口文档编写指南.md)。文档目录和文件使用中文名称；代码标识、URL、JSON 字段和枚举值继续使用英文，以便前后端实现和跨平台工具处理。

文档或接口变更时，应同时更新：

1. 接口参考。
2. 数据结构与枚举。
3. 可解析的 JSON 示例。
4. 后端 Pydantic 模型与接口测试。
