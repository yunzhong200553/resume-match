# 错误码冻结清单

冻结日期：2026-09-24  
契约版本：1.0.0

客户端只允许根据 `error.code` 分支，不得依赖中文 `message`。所有错误响应使用统一外壳：

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "请求字段或模型输出不符合契约。",
    "details": {}
  },
  "requestId": "req_..."
}
```

## 1. HTTP 错误码

| HTTP | 错误码 | 冻结触发条件 |
| ---: | --- | --- |
| 404 | `VERSION_NOT_FOUND` | 创建 Analysis 时指定的 ResumeVersion 不存在 |
| 404 | `ANALYSIS_NOT_FOUND` | 查询或重试指定的 Analysis 不存在 |
| 404 | `SUGGESTION_NOT_FOUND` | 更新指定的 Suggestion 不存在 |
| 409 | `ANALYSIS_IN_PROGRESS` | 对 `processing` Analysis 发起重试 |
| 409 | `ANALYSIS_NOT_RETRYABLE` | 没有失败 Provider，或显式 targets 包含非 failed Provider |
| 409 | `SUGGESTION_STATE_CONFLICT` | 对非 pending 建议重复更新，或并发更新已失效 |
| 413 | `JD_TEXT_TOO_LONG` | `jdText` 去除首尾空白后超过 20,000 字符 |
| 422 | `JD_TEXT_TOO_SHORT` | `jdText` 去除首尾空白后少于 50 字符 |
| 422 | `VALIDATION_ERROR` | 请求 JSON、字段类型、枚举或跨字段组合不合法 |
| 502 | `ANALYSIS_PROVIDER_ERROR` | 同步边界内无法创建或继续任务的 Provider 非法响应 |
| 504 | `ANALYSIS_TIMEOUT` | 同步边界内无法创建或继续任务的 Provider 调用超时 |

`VALIDATION_ERROR` 包括但不限于：未知字段；非法 `targets`；`status` 与 `editedText` 不匹配；Provider 字段缺失、评分越界、维度错误、未知 section/item、`original` 不一致、`targetField` 非 `content`、建议为空/等于原文或越过事实边界。

## 2. 异步失败口径

`POST /api/analyses` 成功创建任务后固定返回 `202`。随后发生的 Provider 超时或响应非法不再把轮询请求改写为 502/504，而是落入 Analysis 与 Provider 状态：

- 单 Provider 失败：Analysis 为 `partial_failed`，失败方 `status=failed`。
- 双 Provider 失败：Analysis 为 `failed`。
- Provider 超时：`providers.*.errorCode=PROVIDER_TIMEOUT`。
- Provider 输出非法：`providers.*.errorCode=INVALID_PROVIDER_RESPONSE`。

顶层 `ANALYSIS_PROVIDER_ERROR` 和 `ANALYSIS_TIMEOUT` 仅用于任务记录创建前或明确同步调用边界中的失败。已创建 Analysis 的客户端以 GET 返回的 `status/providers` 为准。

## 3. Provider 内部错误码

Provider 内部错误码只出现在 `providers.*.errorCode` 或顶层错误的 `details.reason`，不是 HTTP `error.code`：

| Provider 错误码 | 含义 |
| --- | --- |
| `PROVIDER_TIMEOUT` | 单个 Provider 超过配置的调用时限 |
| `INVALID_PROVIDER_RESPONSE` | 非 JSON、字段缺失、额外字段、枚举/评分/ID/事实校验失败 |

`errorMessage` 必须脱敏，不得包含 Coze Token、完整请求、完整响应、简历、JD 或内部堆栈。

## 4. 接口适用范围

| 接口 | 允许返回的模块 B 错误码 |
| --- | --- |
| `POST /api/analyses` | `VERSION_NOT_FOUND`、`JD_TEXT_TOO_SHORT`、`JD_TEXT_TOO_LONG`、`VALIDATION_ERROR`；同步失败边界下可返回 `ANALYSIS_PROVIDER_ERROR`、`ANALYSIS_TIMEOUT` |
| `GET /api/analyses/{analysisId}` | `ANALYSIS_NOT_FOUND` |
| `POST /api/analyses/{analysisId}/retry` | `ANALYSIS_NOT_FOUND`、`ANALYSIS_IN_PROGRESS`、`ANALYSIS_NOT_RETRYABLE`、`VALIDATION_ERROR` |
| `PATCH /api/suggestions/{suggestionId}` | `SUGGESTION_NOT_FOUND`、`SUGGESTION_STATE_CONFLICT`、`VALIDATION_ERROR` |

优化版本创建与导出继续使用模块 A/共享导出服务的错误码，本模块不复制或重命名这些错误。
