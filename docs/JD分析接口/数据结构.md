# 数据结构

## 1. 通用响应

成功响应：

```json
{
  "data": {},
  "requestId": "req_01J8C3A5M7N9P2H4V6K1F0D8QX"
}
```

错误响应：

```json
{
  "error": {
    "code": "ANALYSIS_PROVIDER_ERROR",
    "message": "JD 分析服务返回了无效结果。",
    "details": {
      "failedProviders": ["suggestionAgent"]
    }
  },
  "requestId": "req_01J8C3A5M7N9P2H4V6K1F0D8QX"
}
```

## 2. CreateAnalysisRequest

| 字段 | 类型 | 必填 | 约束 |
| --- | --- | --- | --- |
| `resumeVersionId` | string | 是 | 必须指向存在且不可变的版本 |
| `jdText` | string | 是 | 去除首尾空白后 50-20,000 字符 |

JD 由用户直接输入或粘贴。接口不接受 JD 文件或 URL。

## 3. Analysis

| 字段 | 类型 | 必有 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 是 | Analysis ID |
| `resumeVersionId` | string | 是 | 被分析版本 ID |
| `status` | AnalysisStatus | 是 | 分析整体状态 |
| `jdText` | string | 是 | 本次分析使用的完整 JD |
| `overallScore` | integer \| null | 是 | 0-100；评分不可用时为 `null` |
| `scoreLevel` | ScoreLevel \| null | 是 | `high`、`medium`、`low` |
| `summary` | string \| null | 是 | 总体摘要，评分失败时为 `null` |
| `scoreBreakdown` | ScoreDimension[] | 是 | 四维评分，失败时为空数组 |
| `itemMatches` | ItemMatch[] | 是 | 条目匹配结果 |
| `missingRequirements` | MissingRequirement[] | 是 | JD 缺失要求 |
| `suggestions` | Suggestion[] | 是 | 文本建议 |
| `providers` | ProviderStates | 是 | 两个 Coze 智能体状态 |
| `createdAt` | datetime | 是 | 创建时间 |
| `updatedAt` | datetime | 是 | 最近更新时间 |
| `completedAt` | datetime \| null | 是 | 完成或部分失败时间 |

### 3.1 AnalysisStatus

- `processing`
- `completed`
- `partial_failed`
- `failed`

### 3.2 ScoreLevel

- `high`：80-100
- `medium`：60-79
- `low`：0-59

## 4. ScoreDimension

| 字段 | 类型 | 必有 | 约束 |
| --- | --- | --- | --- |
| `dimension` | ScoreDimensionName | 是 | 固定维度名 |
| `weight` | integer | 是 | 维度满分 |
| `score` | integer | 是 | 0 到 `weight` |
| `reason` | string | 是 | 基于简历证据的简洁理由 |

维度定义：

| `dimension` | `weight` |
| --- | ---: |
| `coreRequirements` | 40 |
| `experienceEvidence` | 30 |
| `skillsCoverage` | 20 |
| `presentationQuality` | 10 |

四个 `weight` 之和必须为 100，四个 `score` 之和必须等于 `overallScore`。

## 5. ItemMatch

| 字段 | 类型 | 必有 | 约束 |
| --- | --- | --- | --- |
| `sectionId` | string | 是 | 必须存在于输入版本 |
| `itemId` | string | 是 | 必须属于对应 section |
| `level` | MatchLevel | 是 | `high`、`medium`、`low` |
| `matchedRequirements` | string[] | 是 | 该条目覆盖的 JD 要求 |
| `reason` | string | 是 | 不超过 300 字 |

## 6. MissingRequirement

| 字段 | 类型 | 必有 | 说明 |
| --- | --- | --- | --- |
| `requirement` | string | 是 | JD 中出现但简历没有证据的要求 |
| `importance` | RequirementImportance | 是 | `required` 或 `preferred` |
| `reason` | string | 是 | 判断依据 |

缺失要求只能用于提醒，不得自动写入简历。

## 7. Suggestion

| 字段 | 类型 | 必有 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 是 | 后端落库后生成；Coze 输出中没有此字段 |
| `analysisId` | string | 是 | 所属分析 ID |
| `sectionId` | string | 是 | 必须存在于输入版本 |
| `itemId` | string | 是 | 必须属于对应 section |
| `targetField` | string | 是 | 首版固定为 `content` |
| `original` | string | 是 | 原条目文本，必须与输入一致 |
| `suggested` | string | 是 | 建议文本，不得为空或等于原文 |
| `reason` | string | 是 | 修改理由，不超过 300 字 |
| `status` | SuggestionStatus | 是 | 建议处理状态 |
| `editedText` | string \| null | 是 | 用户编辑后的最终文本 |
| `createdAt` | datetime | 是 | 创建时间 |
| `updatedAt` | datetime | 是 | 最近更新时间 |

`SuggestionStatus`：

- `pending`：尚未处理
- `accepted`：接受 `suggested`
- `rejected`：保留 `original`
- `edited`：使用用户提交的 `editedText`

建议智能体不得生成 `id`、`analysisId`、`status`、`editedText` 和时间字段，这些字段由后端补齐。

## 8. ProviderStates

```json
{
  "scoreAgent": {
    "status": "succeeded",
    "attempts": 1,
    "errorCode": null,
    "errorMessage": null
  },
  "suggestionAgent": {
    "status": "failed",
    "attempts": 1,
    "errorCode": "PROVIDER_TIMEOUT",
    "errorMessage": "条目建议服务超时。"
  }
}
```

每个 ProviderState 包含：

| 字段 | 类型 | 必有 | 说明 |
| --- | --- | --- | --- |
| `status` | ProviderStatus | 是 | `queued`、`running`、`succeeded`、`failed` |
| `attempts` | integer | 是 | 调用次数，从 0 开始 |
| `errorCode` | string \| null | 是 | 面向程序的错误码 |
| `errorMessage` | string \| null | 是 | 脱敏后的错误描述 |

不得保存 Coze Token、完整请求、完整响应或内部堆栈。

## 9. RetryAnalysisRequest

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `targets` | RetryTarget[] | 否 | 默认只重试失败 Provider |

`RetryTarget` 允许 `scoreAgent` 和 `suggestionAgent`。只有状态为 `failed` 的 Provider 可重试。

## 10. UpdateSuggestionRequest

| 字段 | 类型 | 必填 | 约束 |
| --- | --- | --- | --- |
| `status` | SuggestionStatus | 是 | 只允许 `accepted`、`rejected`、`edited` |
| `editedText` | string \| null | 条件必填 | `status=edited` 时必须为非空文本；其它状态必须为 `null` |

## 11. Coze 契合度智能体输出

仅包含：

- `overallScore`
- `scoreLevel`
- `summary`
- `scoreBreakdown`
- `itemMatches`
- `missingRequirements`

不包含数据库 ID、Provider 状态、建议或时间字段。

## 12. Coze 条目建议智能体输出

```json
{
  "suggestions": [
    {
      "sectionId": "section_project_01",
      "itemId": "item_project_01",
      "targetField": "content",
      "original": "负责后端开发。",
      "suggested": "使用 FastAPI 完成后端接口与数据模型开发。",
      "reason": "明确已有技术和职责，提高与 JD 的相关性。"
    }
  ]
}
```

后端必须检查：

1. `sectionId` 和 `itemId` 存在且归属正确。
2. `original` 与输入版本中的对应内容完全一致。
3. `targetField` 只能为 `content`。
4. `suggested` 不得包含输入中没有的技能、公司、项目、职责、成果或数字。
5. 同一条目的重复建议按 `sectionId + itemId + targetField` 去重。

## 13. 错误码

| 错误码 | HTTP | 说明 |
| --- | ---: | --- |
| `VALIDATION_ERROR` | 422 | 请求或 Provider 输出不符合契约 |
| `JD_TEXT_TOO_SHORT` | 422 | JD 去除空白后少于 50 字符 |
| `JD_TEXT_TOO_LONG` | 413 | JD 超过 20,000 字符 |
| `VERSION_NOT_FOUND` | 404 | 简历版本不存在 |
| `ANALYSIS_NOT_FOUND` | 404 | 分析不存在 |
| `SUGGESTION_NOT_FOUND` | 404 | 建议不存在 |
| `ANALYSIS_IN_PROGRESS` | 409 | 分析执行中，不能重试 |
| `ANALYSIS_NOT_RETRYABLE` | 409 | 没有可重试的 Provider |
| `SUGGESTION_STATE_CONFLICT` | 409 | 建议状态更新冲突 |
| `ANALYSIS_PROVIDER_ERROR` | 502 | Coze 返回非法或不可接受结果 |
| `ANALYSIS_TIMEOUT` | 504 | Coze 调用超时 |
