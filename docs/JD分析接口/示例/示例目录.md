# JSON 示例

## 后端接口

| 文件 | 场景 |
| --- | --- |
| [创建分析请求.json](创建分析请求.json) | 用户选择版本并直接输入完整 JD |
| [创建分析响应.json](创建分析响应.json) | Analysis 已创建，等待两个智能体执行 |
| [分析处理中响应.json](分析处理中响应.json) | 两个智能体正在并行执行 |
| [分析完成响应.json](分析完成响应.json) | 两个智能体均成功 |
| [分析部分失败响应.json](分析部分失败响应.json) | 契合度成功、建议智能体超时 |
| [分析失败响应.json](分析失败响应.json) | 两个智能体均失败 |
| [重试分析请求.json](重试分析请求.json) | 只重试建议智能体 |
| [重试分析响应.json](重试分析响应.json) | 重试任务已接受 |
| [接受建议请求.json](接受建议请求.json) | 接受建议文本 |
| [拒绝建议请求.json](拒绝建议请求.json) | 拒绝建议并保留原文 |
| [编辑建议请求.json](编辑建议请求.json) | 使用用户编辑后的文本 |
| [编辑建议响应.json](编辑建议响应.json) | 建议状态更新成功 |
| [智能体服务错误响应.json](智能体服务错误响应.json) | Coze 返回非法结果 |

## Coze 智能体

| 文件 | 场景 |
| --- | --- |
| [扣子公共输入.json](扣子公共输入.json) | 两个智能体共用的脱敏输入 |
| [契合度智能体输出.json](契合度智能体输出.json) | 智能体 A 的纯 JSON 输出 |
| [条目建议智能体输出.json](条目建议智能体输出.json) | 智能体 B 的纯 JSON 输出 |

所有文件必须保持为合法 JSON，可直接用于前端 Mock、后端契约测试和 Coze 调试。
